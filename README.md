# tools

使用 Rust 编写的常用命令行工具，当前以 Windows 为目标平台。通过解决实际问题，学习从需求设计、模块组织到测试与交付的完整 Rust 项目开发流程。

## 当前状态

- 已有 Cargo 二进制包，包名为 tools，使用 Rust 2024 edition。
- 程序入口目前仅输出 Hello, world!，尚无实际工具功能。
- 第一个工具为文件与文件夹删除命令 remove；参数解析已实现并通过 25 个单元测试，实际删除仍在实现中。
- 换电脑继续前，先阅读 [开发进度与续接](docs/PROGRESS.md)。
- 正式命令名、最低 Windows 版本和分发方式尚未确定。
- 本文档中的 CLI 约定和架构是后续实现的设计基线，不代表功能已实现。

## 项目范围

- 以命令行作为交互入口，逐步添加常用工具。
- 当前只要求支持 Windows；有实际需要时再讨论其他平台。
- 每次完成一个小而完整的功能，再根据经验调整设计。
- 暂不引入 GUI、插件系统、后台服务或通用工具框架。

## 文档维护
